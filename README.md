# Professional Web Security Assessment Lab

A hands-on project focused on assessing intentionally vulnerable web applications and documenting the assessment process.

---

## Overview

This repository contains assessment notes, methodology, and vulnerability reports created while testing intentionally vulnerable web applications in a local lab environment.

---

## Current Setup

- **OS:** Windows 11
- **Platform:** Docker Desktop
- **Target:** OWASP Juice Shop

### Tools

- Nmap
- Wireshark
- Burp Suite Community
- ffuf
- OWASP ZAP

## Repository Structure

- `docs/` – Project documentation
- `findings/` – Individual vulnerability write-ups
- `methodology/` – Testing methodology and checklists
- `notes/` – Session notes
- `reports/` – Assessment reports
- `resources/` – References and learning resources
- `screenshots/` – Supporting evidence
- `tools/` – Tool configuration and setup notes

---

## Rules

- Test only intentionally vulnerable applications.
- Do not test public systems.
- Document every step.
- Understand the purpose before using a tool.

---

## Disclaimer

This repository is created for educational purposes only.

All security testing is performed against intentionally vulnerable applications running in a controlled local lab environment.
